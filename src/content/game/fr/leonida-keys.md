Les Leonida Keys sont un chapelet de petites îles qui file vers le sud-ouest
depuis la pointe sud de l’État, relié par des ponts. La référence réelle,
ce sont les Florida Keys, et la forme les suit de près.

Les îles sont petites, donc ce qui s’y dresse compte plus que leur taille.
La carte communautaire indique une marina et une piste d’atterrissage sur la
plus grande.

On n’a pas montré si la chaîne se parcourt d’un bout à l’autre. Ni comment
les ponts se comportent dans le jeu.

Les Keys n’apparaissent que brièvement dans le matériel publié jusqu’ici.
